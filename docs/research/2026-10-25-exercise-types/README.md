# Новые типы заданий и инструменты для выделенного текста — исследование

Дата: 2026-10-25. Код не менялся. Готовые промпты для задач лежат в [prompts.md](prompts.md).

## TL;DR

1. **Новые детерминированные упражнения стоят дёшево.** Это $0 за вызов, они работают офлайн, а
   данные уже есть в `markedVocab` с `lemma`. Первые кандидаты: «der/die/das», «напиши по-немецки»
   (RU→DE), «собери предложение» и «прослушай и выбери». Один тип занимает ~7–9 файлов и
   **S** по трудозатратам. Главное препятствие не техническое: лимит `max(4)` в двух Zod-схемах и
   отсутствие правила, по которому выбираются показанные упражнения.
2. **Самый большой пробел по сравнению с рынком — повторение вне абзаца.** SRS-очередь
   (`reviewQueue`) считается, но упражнения появляются, только когда пользователь кликает новый
   абзац. У Fluent, Toucan, Language Reactor (PhrasePump) и Clozemaster есть отдельная сессия
   повторения. **M**.
3. **«Инструменты для выделенного» (объяснить, спросить, переписать, разобрать грамматику)
   технически хорошо ложатся на MV3.** Пункт контекстного меню + `chrome.sidePanel`. Ни
   `contextMenus`, ни `sidePanel` не дают предупреждения при установке. Клик по пункту меню выдаёт
   `activeTab`, поэтому инструмент работает **даже на сайтах, где Sprachweise не включён**.
   Хост-страница при этом не трогается вовсе. Нужна поправка в конституцию: принцип III сейчас
   разрешает отправлять выделенный фрагмент только «for translation».
4. **ИИ — серверный Gemini, не встроенный в Chrome.** Prompt API в расширениях стабилен с Chrome
   138 и знает немецкий, но официально поддерживает только `en, ja, es, de, fr`. **Русского в
   списке нет**, а все объяснения у нас на русском. К тому же нужны 16 ГБ RAM, >4 ГБ VRAM и 22 ГБ
   диска. Writer/Rewriter/Proofreader всё ещё в developer trial.
5. **Ориентиры по цене** (Gemini 3.8 Flash, `apps/cms/src/pipeline/pricing.ts`): «объяснить
   фрагмент» ≈ $0.004, одно сообщение чата ≈ $0.003. С 2027-01-01 цена 3.8 Flash удваивается.
   «Объяснить» и «переписать» кэшируются так же, как перевод. Чат не кэшируется, и без лимитов
   на установку его выпускать нельзя (лимиты отложены до ревью 16 Nov).
6. **Сроки.** `docs/ship-first-dollar.md` явно вырезает «grammar topics» и «new exercise types»
   из текущей фазы. Всё ниже — бэклог **после ревью 16 Nov 2026**, ни одна из этих задач не
   входит в private beta.

## 1. Что есть сейчас (по коду)

| Звено | Где | Как устроено |
| --- | --- | --- |
| Точка входа | `entrypoints/content/index.tsx` | Клик по «подходящему» абзацу (`paragraph-parser`, лимит плотности) на **включённом** сайте. Выделение текста не используется. |
| Перевод | `apps/cms/src/pipeline/translate.ts` | Один structured-output вызов Gemini: немецкий текст под CEFR + 3–8 слов `{german, lemma, russian}`. Двойной кэш: Postgres на сервере (ключ — текст+уровень+модель+thinking+promptVersion) и IndexedDB в расширении. |
| Упражнения | `apps/cms/src/exercises/generate.ts` | **Детерминированно, без LLM**, ≤4 штук: word-pairing, fill-blank (подсказка — русская глосса), multiple-choice (дистракторы — другие слова абзаца), audio-dictation. |
| Контракты | `packages/shared/src/schemas/{cms,storage,messages}.ts` | `CmsExerciseSchema` и `ExerciseSchema` — discriminated union из 4 kind. `ExercisesResponseSchema` и `ExerciseSetSchema` ограничены `.max(4)`. `AnswerPayload = string \| number \| Record<string,string>`. |
| Проверка | `apps/extension/lib/exercises/match.ts` | В background. Нестрогое сравнение: регистр, пунктуация, ä↔ae, ß↔ss. |
| UI | `entrypoints/content/overlay/*` | React-панель в Shadow DOM на странице (`createShadowRootUi`), `switch` по `kind` в `Panel.tsx`. Это не `chrome.sidePanel`. |
| Прогресс | `lib/storage/progress.ts`, `lib/srs/scheduler.ts` | SM-2-подобный SRS по `vocabId` (лемма), streak, `topicAccuracy[topic]`. Топик всегда `"general"`: грамматические темы вырезаны. |
| Озвучка | `lib/audio/play-dictation.ts` | `speechSynthesis`, предпочитает голос `de-DE`. Серверного TTS нет. |

Ограничения, которые определяют решения ниже (`.specify/memory/constitution.md` 2.0.0):

- **I. Least Privilege.** Каждое новое разрешение требует письменного обоснования.
- **II. Host Page Integrity.** UI только в Shadow DOM. Подмена текста обратима и только в
  выбранных блоках.
- **III. Privacy.** С устройства может уйти только «the selected fragment, for translation»,
  install ID (только с метриками) и отчёт «Плохой перевод».
- **IV. Offline-First.** Слова, SRS и уже полученные данные работают без сети.
- **V. Typed Contracts.** Zod на каждой границе.
- **VII. YAGNI.** Не вводить общую абстракцию до третьего реального случая.

> Расхождение с описанием проекта: бэкенд **лежит в этом репо** (`apps/cms`, Fastify на Vercel +
> Neon), а не в отдельном Payload CMS. `/api/tts` удалён, озвучка идёт через `speechSynthesis`.

### Сколько стоит добавить один тип упражнения

Каждый новый `kind` затрагивает:

1. `packages/shared/src/schemas/cms.ts` — новый член `CmsExerciseSchema`.
2. `packages/shared/src/schemas/storage.ts` — `ExerciseKindSchema`, новый `*ExerciseSchema`,
   `ExerciseSchema`. При необходимости поднять `ExerciseSetSchema.max`.
3. При необходимости `messages.ts` → `AnswerPayloadSchema` (например, для массива).
4. `apps/cms/src/exercises/generate.ts` — генерация.
5. `apps/extension/lib/exercises/generate.ts` — маппинг CMS → сущность.
6. `apps/extension/lib/exercises/match.ts` — проверка.
7. `entrypoints/content/overlay/<Kind>Card.tsx` + ветка в `Panel.tsx`.
8. Тесты: `packages/shared/tests/schemas.test.ts`, `apps/cms/tests/unit/generate-exercises.test.ts`,
   `apps/extension/tests/unit/match.test.ts`, при необходимости Playwright
   `exercise-panel.spec.ts` и mock CMS.

Расширять union обратно совместимо: старые закэшированные наборы продолжают парситься. **Поднять**
`max(4)` безопасно, **понизить** — нет: старый кэш упадёт на `safeParse` и тихо станет пустым.

Как только типов становится больше 4, нужна **политика выбора**: какие ≤N показать для абзаца.
Варианты: ротация по типам, приоритет словам с подошедшим `dueDate`, не больше одного упражнения
на слово. Это первое место, где оправдана небольшая общая логика.

## 2. Что делают другие

| Продукт | Тип | Что полезно для нас |
| --- | --- | --- |
| Duolingo | приложение | Перевод, «tap pairs», **listen-and-tap** (собрать фразу из банка слов на слух), «speak the correct response». В Max: **Explain My Answer** (чат «почему мой ответ неверен») и **Roleplay** с разбором ответов. |

| Language Reactor | расширение | Двойные субтитры, словарь, поиск предложений по слову или грамматической форме, **PhrasePump** — повторение через предложения с «созревшими» словами, экспорт в Anki. |
| Migaku | расширение/приложение | **ИИ-объяснение слова в контексте, разбор предложения пословно**, перевод предложения. Ближайший аналог нашего «Объяснить». |
| Trancy | расширение | ИИ-активности поверх субтитров. |
| Mate | расширение | Сохранённые слова + SRS, работает офлайн. |
| DeepL Write | веб/API | Переписывание в **стилях** (simple, business, academic, casual) и **тонах** (friendly, diplomatic, confident, enthusiastic). Немецкий поддерживается. Образец для «Переписать». |
| LanguageTool | веб/API, open source | Проверка немецкой грамматики. Бесплатный API: 20 запросов/мин, 75k символов/мин, 20k на запрос. Можно развернуть у себя. |

Выводы:

- **Чтение + подмена + слова** — устоявшаяся ниша (Toucan, Fluent). Наше отличие: целый абзац под
  уровень CEFR и упражнения по конкретному тексту. Его стоит усиливать.
- Почти у всех есть **отдельное повторение**, у нас нет.
- **ИИ-разбор выделенного** (Migaku, Duolingo Explain My Answer) — сейчас главная премиум-фича в
  нише. Её логично сделать платной частью, когда появится Pro.
- По упражнениям, сгенерированным LLM, немецких оценок не нашлось. По английским: у GPT-3.5 в
  cloze ~75% предложений и ~67% вариантов ответа признаны корректными. Значит, **LLM-упражнения
  нельзя выпускать без прогона качества**, как в `docs/quality/2026-10-19`. Детерминированные
  упражнения поверх уже проверенного перевода надёжнее.

## 3. Каталог фич и оценка сложности

Шкала трудозатрат: **S** — до 1 дня работы агента + ревью, **M** — 2–4 дня, **L** — 1–2 недели,
**XL** — больше. «$/исп.» — оценка по ценам `pricing.ts` для `gemini-3.8-flash` ($0.75 / $3.75 за
1M токенов входа/выхода, thinking `low`). Объёмы токенов — моя прикидка, не замер.

### A. Новые упражнения по абзацу (текущий поток «клик → панель»)

| # | Фича | Откуда данные | Проверка | $/исп. | Офлайн | Трудоз. | Риски |
| --- | --- | --- | --- | --- | --- | --- | --- |
| A1 | **der / die / das** — выбрать артикль леммы | `lemma` из глосс уже содержит артикль («das Riesenrad») | точное совпадение | 0 | да | **S** | Нужен разбор «die Leute» (только мн.ч.) и лемм без артикля. Качество зависит от глосс, а prompt v2 уже исправлял артикли. |
| A2 | **Напиши по-немецки** (RU → лемма) | `markedVocab` | нестрогое совпадение, допуск артикля | 0 | да | **S** | Синонимы: русская глосса может соответствовать нескольким немецким словам, нужна кнопка «Я был прав». |
| A3 | **Собери предложение** (Satzbau) — перетасованные слова | предложение абзаца 4–9 слов | совпадение с оригиналом | 0 | да | **S–M** | В немецком свободный порядок перед глаголом: «Gestern ging ich…» и «Ich ging gestern…» оба верны. | A4 | **Прослушай и выбери** | предложение + 2 дистрактора из других предложений | индекс | 0 | да (голос de-DE обязателен) | **S** | Без голоса de-DE упражнение не показывать. |
| A5 | **Вопросы на понимание** (верно/неверно, MC) | LLM: добавить `comprehension[]` в structured output перевода | индекс | +~$0.0005 к переводу | да (генерируется вместе с переводом и кэшируется) | **M** | Меняется промпт → `PROMPT_VERSION` → инвалидация кэша. Нужен прогон качества. |
| A6 | **Грамматические пропуски**: окончания прилагательных, артикль в падеже, предлог+падеж, haben/sein в Perfekt, отделяемая приставка | LLM-разметка токенов (POS, падеж, род, число, время) в том же вызове; упражнения строятся детерминированно по разметке | точное совпадение | +~$0.001 к переводу | да | **L** | Ошибки морфологической разметки превращаются в неверные упражнения. | A7 | **Трансформация** (Präsens→Perfekt, Aktiv→Passiv, «… weil …») | LLM генерирует задание + 1–3 принятых ответа | нестрогое совпадение со списком, затем «проверить ИИ» | ~$0.002 | частично | **L** | Свободный ответ: ложные «неверно» раздражают сильнее всего. |
| A8 | **Перевод предложения RU→DE** с оценкой ИИ | исходный абзац + немецкий вариант | LLM на каждую попытку | ~$0.002 за попытку | нет | **M–L** | Расход на каждую попытку, нужны лимиты на установку. |
| A9 | **Произношение** (повтори фразу) | `SpeechRecognition` (`processLocally`, de-DE) | сравнение транскрипта | 0 (on-device) | да, если модель скачана | **спайк, L** | Микрофон в content script запрашивается **от имени сайта** (виден домен хоста). Безопаснее страница расширения (side panel). Точность on-device для «оценки произношения» не подтверждена. |

### C. Инструменты для выделенного текста

**Точка входа — рекомендация.** Пункт контекстного меню «Sprachweise ▸ Объяснить / Грамматика /
Переписать / Спросить / Озвучить / В словарь» плюс ответ в **`chrome.sidePanel`**:

- `contextMenus` и `sidePanel` **не дают предупреждения при установке**. Подходит под принцип I с
  обоснованием в одну строку.
- `info.selectionText` приходит прямо в `contextMenus.onClicked` в background. **Content script
  не нужен**, хост-страница не меняется. С принципом II проблем нет.
- Клик по пункту меню **выдаёт `activeTab`**. Можно работать на любом сайте, без
  `optional_host_permissions` и без включения сайта. Это сильный канал привлечения: инструмент
  доступен с первой минуты после установки.
- `sidePanel.open()` разрешено вызывать из `contextMenus.onClicked` (пользовательский жест).
  Side panel — страница с origin расширения: React без Shadow DOM, чат, история, микрофон (A9).
- Дополнительно позже: горячая клавиша через `commands` (тоже даёт `activeTab`) и плавающая кнопка
  у выделения на **включённых** сайтах. Кнопка заметнее, но назойливее (принцип VIII), поэтому
  второй очередью.

Альтернатива — popover в Shadow DOM рядом с выделением на включённых сайтах. Она проще для
коротких ответов, но не работает на невключённых сайтах, и в ней неудобно вести чат. Её можно
оставить для «Озвучить» и «Перевести».

**Ограничения выделения.**

- Длина: ограничить, например, 1–600 символами. Сервер уже проверяет `TRANSLATE_MAX_CHARS`.
- Язык: немецкий (пользователь читает немецкий сайт) или RU/EN (тогда сначала переводим нашим
  пайплайном). Язык можно определить на устройстве через Language Detector API (стабилен с
  Chrome 138) или отдать LLM.
- **Подменять текст на месте для произвольного выделения не нужно.** Range может пересекать
  несколько узлов и частично захватывать блоки. Обратимое восстановление (принцип II) там намного
  сложнее, чем у нынешней блочной подмены. Результат показываем в панели.

| C7 | **Проверь мой немецкий** — пользователь пишет фразу, получает исправления | LLM или LanguageTool (`de-DE`, self-host или free API 20 req/min) | ~$0.002 / 0 | нет | **M** | Писать в поля ввода хост-страницы **нельзя** (принцип II). Ввод только в side panel. |

### D. Где запускать ИИ

| Вариант | За | Против | Вывод |
| --- | --- | --- | --- |
| **Серверный Gemini** (уже есть) | Проверенное качество (судья 4.86 у 3.8-flash), structured output, общий кэш, учёт в `provider_calls` | Цена; онлайн-only; глобальный лимит `GEMINI_DAILY_REQUEST_ALLOWANCE=1500` в день делится между всеми | **Основной путь.** Новым эндпоинтам — свой счётчик в `usage_counters`, чтобы чат не съел лимит переводов. |
| Chrome Prompt API (Gemini Nano) | $0, офлайн, ничего не уходит с устройства | Языки только `en, ja, es, de, fr`, **без русского**. 16 ГБ RAM, >4 ГБ VRAM, 22 ГБ диска, только десктоп. Скачивание модели при первом `create()`. Качество немецкой грамматики не измерено. | Позже — опционально для задач «немецкий → немецкий» (переписать, примеры), с откатом на сервер. |
| Writer / Rewriter / Proofreader API | Узко подходят под C5/C7 | **Developer trial** — в стор с этим нельзя | Не использовать. |
| Translator / Language Detector API | Стабильны с Chrome 138, на устройстве | Пары языков для `ru` проверить | Language Detector — для определения языка выделения в C0. |
| LanguageTool | Детерминированная проверка немецкого, open source | Java-сервер (не Vercel function), отдельный хостинг; бесплатный API 20 req/min на IP | Для C7 и, возможно, как фильтр качества LLM-предложений. Не первым делом. |

**Проверка свободных ответов** (A2, A7, C4, C7). Гибрид:

1. Нестрогое сравнение со списком принятых ответов (генерируется вместе с заданием). Работает
   офлайн, $0.
2. При «неверно» — кнопка «Проверить ИИ» / «Я был прав»: разовый вызов, засчитывает попытку
   задним числом.

Так основная масса проверок остаётся детерминированной (принцип IV), а ИИ тратится только на
спорные случаи.

## 4. Экономика

- Перевод абзаца с 3.8-flash ≈ $0.002 (≈450 входных / ≈400 выходных токенов). В
  `ship-first-dollar.md` старая оценка ~$0.001 была для 3.5-flash-lite.
- Если ИИ-инструменты бесплатны и без лимитов, они быстро станут самой дорогой частью. Активный
  пользователь с 10 объяснениями и 20 сообщениями в день ≈ $0.10/день ≈ $3/мес — почти вся
  выручка с $4 Pro, а с 2027-01-01 вдвое больше.
- **Рекомендация:** C3 и C5 кэшируются, их можно дать бесплатно с дневным лимитом на установку. C6,
  C7 и A8 — Pro. Это прямо связано с отложенным решением 4 из `ship-first-dollar.md`.

## 6. Изменения в конституции и политиках, которые понадобятся

- **III Privacy (MINOR-поправка).** Разрешить отправку «выделенного пользователем фрагмента для
  перевода **или для учебного инструмента, вызванного на нём явным действием**». Для C6/C7 —
  «текста, который пользователь сам ввёл в инструмент». URL/hostname по-прежнему запрещены. Сейчас
  `contextMenus.onClicked` получает `info.pageUrl`, и его нельзя передавать дальше.
- **I Least Privilege.** Обоснования для `contextMenus` и `sidePanel` (без предупреждений).
  Для B2 — `alarms`, если понадобится.
- `apps/cms/src/privacy/policy.ts` и `docs/store-listing.md` — новые цели обработки, обоснования
  разрешений для стора.
- Метрики (`MetricEventSchema`) — события `tool_used{tool}` без текста. `exercise_completed`
  можно расширить полем `kind`, чтобы видеть, какие типы решают.
